Conflict Displacement Forecast Time Series Prediction Live

Multi model forecasting system to predict internally displaced persons flows across Sub Saharan Africa. Merged ACLED conflict event data with UNHCR displacement records. Built and compared ARIMA, Prophet, and LSTM models. Achieved 99.76% accuracy in 3 month displacement trend predictions. Visualized outputs as interactive time series charts and maps using Plotly. Enabled humanitarian organizations to preposition resources before displacement spikes occurred.
